# 050 — wp5: opencode 런처 이식

work-phase: `wp5` · 선행: `010` · 순서 정본: `006`

## 왜 CLI 슬라이스의 마지막인가

`src/cli/opencode.ts`는 701줄로 다른 명령을 모두 합친 것과 비슷하다. 게다가 순수 래퍼가
아니라 **프로세스 런처**다: 프록시 기동/탐색, 카탈로그 조회, 설정 병합, 어드미션 토큰
주입, 외부 바이너리 실행이 한 줄기로 엮여 있다. 앞선 슬라이스의 원시요소가 모두 확정된
뒤에 손대야 한다.

## 선결 결정: `/api/models` 응답 계약

오라클 런처는 `GET /api/models` 응답 **본문 자체가 배열**이라고 가정한다
(`src/cli/opencode.ts:401`). Go 관리 서버는 `{models, customModels}` 객체를 반환한다
(`go/internal/management/models.go:15`).

세 가지 선택지:

| 안 | 내용 | 평가 |
| --- | --- | --- |
| A | Go 런처가 객체·배열 양쪽을 수용 | 클라이언트 측 국소 변경, 서버 계약 불변. **채택** |
| B | Go 서버 응답을 배열로 변경 | 기존 Go GUI/소비자 파손 위험, 다른 파리티 테스트와 충돌 |
| C | 오라클을 객체 수용으로 변경 | `src/**` 수정 — 스코프 위반 |

**A안 채택 — 단, 런처 국소 수정으로만.** 근거: 서버 응답 형태를 이 슬라이스에서 바꾸면
`differential` 테스트가 비교하는 관리 응답 바이트가 함께 흔들린다. 런처는 응답을 소비할
뿐이므로 수용 범위를 넓히는 것이 이 슬라이스에서 가장 좁은 변경이다.

### 감사 B3 정정 — 이것은 평범한 잔여가 아니다

처음에는 "`120`에서 별도 항목으로 재측정"이라고만 적었다. 감사가 지적한 대로 그것은
`004`의 계약("Go가 TS와 다르면 Go가 틀렸다")과 충돌하고, 런처 테스트가 통과하는 동안
**공개 관리 API가 비파리티로 남은 채 DONE이 될 수 있다.**

따라서 서버 응답 형태 차이를 **`NEEDS_HUMAN` 파리티 예외 후보로 승격**한다:

- 이 항목이 미해결인 한 `120`은 `DONE`을 선언할 수 **없다**.
- 해소 경로는 둘 중 하나이며, 어느 쪽도 이 슬라이스가 임의로 고르지 않는다.
  1. Go 서버 응답을 오라클 형태로 이식하고 기존 Go 소비자(GUI 포함) 마이그레이션과
     회귀 테스트를 함께 제공한다.
  2. 사용자가 명시적으로 파리티 예외를 승인한다.
- 어느 쪽도 없으면 터미널 결과는 `NEEDS_HUMAN`이다.

런처가 두 형태를 모두 받는 것은 이 결정과 **무관하게** 유효하다 — 런처는 어차피 견고해야 한다.

## 오라클 동작 골격

`src/cli/opencode.ts:645` 이하 런처 흐름:

1. OCX 프록시 기동/생존 확인
2. `GET /api/models`로 카탈로그 조회
3. `OPENCODE_CONFIG_CONTENT` 환경변수 병합
4. 어드미션 토큰 주입
5. 디스크상의 충돌하는 `opencode` 설정이 있으면 경고
6. 나머지 인자를 외부 `opencode` 바이너리에 그대로 전달

서브명령 파싱은 없다. 인자는 통과된다.

## 수용 기준

| # | 기준 | 활성화 시나리오 | 증거 |
| --- | --- | --- | --- |
| 1 | 배열 응답 수용 | 스텁이 `[{...}]` 반환 | 카탈로그 파싱 성공 |
| 2 | 객체 응답 수용 | 스텁이 `{"models":[...],"customModels":[]}` 반환 | 동일 카탈로그 |
| 3 | 어드미션 토큰이 환경으로 주입 | 주입 가능한 exec 스텁 | 기록된 env에 토큰 존재 |
| 4 | 인자가 변형 없이 전달 | `opencode run --flag x` | 기록된 argv가 `run --flag x` |
| 5 | 디스크 설정 충돌 시 경고 | 충돌 설정 파일 배치 | stderr 경고 1회, 실행은 계속 |
| 6 | 바이너리 부재 시 명확한 오류 | PATH에서 제거 | 오라클과 동일한 오류 문구 |
| 7 | 토큰이 로그·오류에 노출되지 않음 | 실패 경로 강제 | 출력에 토큰 문자열 부재 |
