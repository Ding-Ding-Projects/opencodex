# 006 — 전역 의존성 DAG (정본)

감사 2라운드 블로커 5에서 생성. **이 문서가 순서에 관한 유일한 정본이다.** 각 십진 문서
머리말의 "선행/후속" 줄과 `003`의 순서 문단이 충돌하면 이 문서가 이긴다.

## 원칙

간선은 **뒤 단계가 앞 단계가 만든 구체적 심볼·API·파일을 소비할 때만** 긋는다.
"이게 더 중요해 보인다"나 "이걸 먼저 하는 게 자연스럽다"는 간선이 아니다.

## 그래프

```
wp0 (문서화)
 │
 ├─> 010 ──┬─> 020   combo/route, agent, grok/integration
 │         ├─> 030   system, observe
 │         ├─> 040   access/api-key
 │         ├─> 045   config 파리티
 │         ├─> 046   account 인증
 │         └─> 050   opencode 런처
 │
 ├─> 060   보안/플랫폼          ──> 130  Windows UAC
 ├─> 070   OAuth 계정 풀
 ├─> 080.1 ─> 080.2 ─> 080.3 ─> 080.4   스토리지
 ├─> 090.1 ─> 090.2                     SSE ─> 이미지
 ├─> 100   관리/레지스트리
 ├─> 110.A 관측성
 ├─> 110.B Kiro
 └─> 110.C Desktop/업데이트/키
 │
 └─> (전부 완료 후) 120 수렴
```

## 간선 근거

| 간선 | 소비되는 구체적 산출물 |
| --- | --- |
| `010 → 020/030/040/045/046/050` | `runtimeRequest`, `CLIUsageError`, `take*` 파서, `redactSecretArgs`, `printData` |
| `080.1 → 080.2` | `ArchivedCandidate`, `ComputePreviewDigest`, 후보 해석기 |
| `080.2 → 080.3` | 뮤테이션 조정자, 스테이지/manifest, 위성 백업 |
| `080.3 → 080.4` | 복원 경로(정책이 격리 모드로 호출) |
| `090.1 → 090.2` | `RelaySSEWithPayloadRewrite`, `ComposeSSEPayloadRewrites` |
| `060 → 130` | ACL 플래너 정리 후 승격 트랜잭션이 그 위에 앉음 |
| `* → 120` | 수렴은 정의상 전부 이후 |

## 간선이 **아닌** 것 (초안에서 잘못 그었던 것)

| 잘못된 간선 | 왜 아닌가 |
| --- | --- |
| `020 → 030` | 둘 다 `010`만 소비한다. 서로의 심볼을 쓰지 않는다 |
| `060 → 050` | 런처와 보안 경계는 무관하다 |
| `070 → 080` | 계정 풀과 스토리지는 공유 심볼이 없다 |
| `080 → 090` | 스토리지와 SSE는 무관하다 |
| `100 → 110` | 무관 |

## 실행 함의

`010` 완료 후 CLI 여섯 슬라이스는 임의 순서·병렬 가능. 런타임 계열
(`060`, `070`, `080.1`, `090.1`, `100`, `110.A/B/C`)은 서로 독립이므로 `wp0` 직후 어느 것이든
시작할 수 있다. 하나가 막혀도(`130`이 Windows CI로 `BLOCKED`가 되더라도) 나머지는 진행한다.

`110.A`만 예외적 주의: `conversationId` 필터는 로그 엔트리 필드를 먼저 추가해야 하므로
슬라이스 **내부** 순서가 있다(필드 → 기록 배선 → DTO → 필터).
